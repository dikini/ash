Reader setup

Prepare Ash

The learning path uses the ash command-line tool. You need Git and a Rust toolchain that includes Cargo. Clone Ash with its Git URL, select the exact commit for this edition, and build it:

git clone git@github.com:dikini/ash-lang.git
cd ash-lang
git switch --detach 354c76b391fe4af665cf6a03479a9874a57cb3e3
cargo build --locked

The executable is now target/debug/ash. Make the shorter name ash available in the current terminal:

export PATH="$PWD/target/debug:$PATH"
export ASH_LIBRARIES="$PWD/libraries"
export ASH_NATIVE_CACHE="$PWD/target/ash-doc-native"

Keep this terminal open while you work through the learning path. ASH_LIBRARIES selects the same checkout’s source libraries. The buffer lesson uses it with --root ffi="$ASH_LIBRARIES"; ordinary lessons need no root option. ASH_NATIVE_CACHE lets successive native builds reuse their dependencies. Native buffer builds currently require Linux x86-64 GNU, the matching Rust toolchain, cached Cargo dependencies, and a native linker. Their generated executables print a value without the interpreter’s : Type suffix.

Read a diagnostic

When a lesson shows a rejected program, its transcript includes the command and the complete English message. A leading $ marks the shell prompt; do not type it. --message-format human --locale en selects that presentation explicitly. This compiler’s human renderer emits plain text without terminal color; it has no color option to set.

Ash prints canonical absolute source paths. In the displayed messages, only the checkout prefix is replaced by /path/to/ash-doc/. Your terminal will show your checkout’s actual location. The remainder of each path, source excerpt, label, and message is unchanged. Run the named checked-in example from the working directory given by its learning path to compare the message directly. A copy saved with another filename will naturally show that name instead.

Read the explanation first, then follow its source labels back to the program. The reason: line gives a secondary identifier for the kind of failure; it is not a replacement for the explanation. These source rejections write their messages on standard error, leave standard output empty, and exit with status 1.
