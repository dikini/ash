# Agent Semantic Workspace

This directory holds exploratory product material for the Agent Semantic Workspace: a separate,
Ash-implemented workspace product and a primary dogfooding application for Ash runtime features.
It is not an Ash language specification and does not by itself authorize language, runtime, or
standard-library changes.

- [Product requirements document](agent-semantic-workspace-prd.md)
- [Dogfooding and unified-interface addendum](agent-semantic-workspace-addendum.md)

The product is deliberately pre-standardization. Any capability promoted into Ash must receive its
own Ash specification, implementation, conformance evidence, and compatibility decision.
