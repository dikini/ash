Different readers arrive with different questions. Start with the route that matches yours, then follow the examples into deeper material.

## Already write programs?

[Take the short language tour](/ash/learn/tour/). It assumes familiarity with functions and types, then shows how Ash expresses data and effectful calculations. Each example is a complete program you can run.

Continue with [installation and first execution](/ash/docs/install/) and the [documentation](/ash/docs/) when you want precise instructions.

## New to programming

Start with [Study Ash](/ash/study/), which points to the guided learning material in ash-doc. The opening lessons introduce expressions, values, functions, and running a first program. Later lessons build toward data, recursion, and abstraction.

The current setup requires a text editor, a terminal, Git, and a Rust toolchain. The study edition's setup instructions cover installation; its compiler checkpoint differs from the website tour.

When working through an example, predict its result before running it. Compare the actual result with your prediction, change one thing, and explain what changed.

## Follow a deeper question

The study material continues through Libraries, Effects, and worked Cases. Read it as a connected work, with its own reading order and exercises. For a precise rule, use the specification linked for the same language target.
