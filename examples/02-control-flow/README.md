# Control Flow Examples

This directory demonstrates control flow patterns in Ash workflows.

## Files

### 01-conditionals.ash
If/then/else branching:
- Simple conditionals
- Multiple else-if branches
- Using conditions in workflow control

### 02-foreach.ash
Looping constructs:
- Iterating over lists
- Pattern matching in loops
- Accumulating results

### 03-sequential.ash
Sequential composition:
- Composing operations in order
- Building on previous steps
- Sequential data processing

## Key Concepts

1. **Conditionals** choose between branches
2. **For loops** iterate over collections
3. **Sequential composition** chains operations in order
