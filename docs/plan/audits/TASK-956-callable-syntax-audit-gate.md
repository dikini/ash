# TASK-956 Callable Syntax Audit Gate

## Scope

This audit maps the live callable syntax implementation before PLAN-121 Rust behavior changes. It covers parser, typechecker, rendering, module import/export, closure lowering/runtime, stdlib syntax exposure, and reference exposure for SPEC-072.

TASK-956 does not implement parser, typechecker, runtime, stdlib, or reference migrations. TASK-957 through TASK-960 and TASK-963 own those changes.
