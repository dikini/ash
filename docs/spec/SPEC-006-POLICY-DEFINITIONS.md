# SPEC-006: Retired Policy Definition Syntax

This specification is retired. Ash no longer defines a dedicated `policy` declaration,
policy-expression, policy-binding, or policy-runtime route. The former surface is not accepted,
lowered, admitted, persisted, or executed, and no compatibility behavior is required.

Host sandbox/provenance configuration and provider-specific policy data are separate host/runtime
contracts and are not language policy declarations.

See TASK-2077 and the current module/language specifications for the supported surface.
