# SPEC-024: Retired Capability-Role Surface

This specification is retired. Ash no longer defines the dedicated capability-role workflow
surface, including role declarations, role inclusion, role-yield syntax, or role runtime
semantics. No backwards-compatible parser, lowering, admission, or execution route is retained.

Host/provider capability and sandbox contracts are separate runtime interfaces and are not this
language surface.

See TASK-2077 and the current module/language specifications for the supported surface.
