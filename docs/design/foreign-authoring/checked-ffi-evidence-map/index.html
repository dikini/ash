All design notes

This map belongs to CP-0024 and TASK-0050. It translates every canonical transition into required future evidence. All rows are pending. No entry is an executed product result.

For O/X/K common rows, test both modes where the event exists; isolated-only events need a corresponding explicit in-process limit statement, not a fabricated process domain. Test every L/T library row against the actual generated SQLite bridge in both modes where feasible; impossible native combinations use labeled injected faults. Pair real native behavior with protocol/bridge fault injection rather than pretending SQLite naturally emitted contradictions. Observe entry count, exact pending/control state, value publication, K, required source continuation and protected dependency edges separately. Check receipts against frozen source, contract, Core/image, native inputs and policy before transferring evidence.

F3 owns summary/link/Core rejection and transformed-contract tests; F4 owns common runtime/ownership/completion; F5 owns ordinary source-library realization; F6 owns build/image/receipt admission; F7 owns isolated transport/executor realization. F8 audits the complete map and F-core/F-final gates. These issue keys refer to the task plan, not launched product tasks.

Coverage beyond individual rows

Run every distinguishing trace in the canonical table, including overlapping K reasons, terminal failure versus healthy loss, original-kind caching after refusal, binding uncertainty across reset, and consumption before reporting loss. One test may cover multiple rows only with observations for each obligation.

F3 must additionally reject same-spelled origins, wrong full Type/Row substitutions, opaque alias substitution, forged independence, hidden captured S/C/H, host-row erasure, stale summaries and transformed copy-window order. Validate imported wrappers without reinferring their bodies. Preserve nearest ordinary-handler precedence and source finish control through capture/resume/discard/cleanup.

F6/F7 need approved exact bytes/receipt closure, changed-image races, wrong ABI, unavailable-control refusal, fresh session identity, malformed versus plausible false replies, actual launch/resource enforcement and delayed reaping. See the experiment contract. Stage A environmental probes do not satisfy any product row. Missing observation, integrated correspondence, independent review or required checkpoint keeps the original criterion pending.
