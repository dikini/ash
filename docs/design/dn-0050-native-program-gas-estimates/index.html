Initial accepted pilot and its calibration

Keep the actual cumulative work meter. Compute finite gas from resident input, without a static overall ceiling or per-module resets:

P = admitted source UTF8 bytes + validated main Core node count
B = canonical image bytes + canonical expected-fact bytes
preparation gas = 24 * P
startup gas     = 7 * B

P is available before image construction. Read resident string lengths and the main arena length; do not reopen source paths, walk expanded Type/Row trees or replay construction. A test-only sizing loop charges one unit for the node count and one per source before reading its length. Its finite bootstrap is the actual source count plus one. Carry this work inside the computed total, refuse arithmetic overflow or a total below work already spent, and never reset or add spent gas as a top-up.

Choose each coefficient as the ceiling of 1.25 times the largest FIT ratio. Preparation includes the new sizing cost in the observed total:

Coefficient Largest FIT ratio With chosen 25% reserve Rounded upward
Preparation (previous whole work + sizing) / P 18.748480 23.435600 24
Startup whole work / B 5.423416 6.779271 7

There is no fitted intercept. The 25% reserve is an engineering choice, not a statistical confidence bound. Neither proxy is a universal cost bound. The actual meter refuses amplification or unexpectedly expensive validation. Source whitespace, admitted unused source and valid unused framed records can increase gas linearly. Trailing or unframed bytes receive no startup credit. Compact DAGs receive no exponential credit.
