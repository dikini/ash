AD-0015 selects the narrow owner-free scalar GNU in-process architecture. The owner acceptance readback records explicit delegated acceptance after independent preparation review. This evidence creates no per-image strict approval, startup authority or configured deployment.

The exact closure premise example is preserved byte-for-byte from the reviewed proposal. Its PROPOSED/non-authorizing status is intentional: it demonstrates data associations, not an approved executable record or a second authority mechanism. It binds the actual existing-profile baseline and immutable producer receipt. That baseline supplies no checked contract closure and cannot approve checked execution. Its null administrator context and pending admission-work mechanism must not be accepted by a product launcher. F6 must implement those associations and refuse their absence.

The source audit conclusion, retained as exact original text, supports a conditional C-locale/gettext argument and preserves unresolved routes and provenance limits. The exact audit manifest pins the original 81 source/patch/metadata/research files. Their original contents remain external under /tmp/ash-checked-ffi-inprocess-design/glibc-source-audit; the repository does not vendor glibc/Rust sources or claim every recorded external file is present here. Official immutable source links are in the conclusion. The full manifest includes historical failed-fetch metadata and acquisition scripts; those are provenance, not product tools or execution instructions. Source retrieval does not reproduce the patched distribution build or establish all indirect runtime behavior. Original sources can be reacquired by the pinned import and paths; local package/build records require the recorded environment.

Transferred generated Ash packaging and separately approved diagnostic retain actual whole-static linking and sealed-fd Returned(7) with observed reaping. That diagnostic accepted possible loading. Its approval is inapplicable to the strict closure policy. No original producer receipt, policy, approval, harness or observation is rewritten by this decision.

The decision accepts trusted runtime/native closure conformity as an explicit in-process premise; structural ELF facts, conditional source evidence and this premise remain distinct. Nine temporary link inputs are missing and the Ubuntu source import is patches-unapplied. These limits are bound in the example. No formal whole-libc guarantee, trace-derived proof, isolation or protection against faulty native memory is asserted. Strict per-image approval, protected store/context enforcement and connected F4/F6 implementation/tests remain pending. Whole F2 criteria remain unchecked.

These notes record research, alternatives, and evidence at the source revision linked above. Their status is preserved in each document.
