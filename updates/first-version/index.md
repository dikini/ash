# A public home for an evolving language

> The first website version brings discovery, language status, and study entry points together.

This first local website version establishes a public-facing structure for Ash: a concise introduction, runnable tour programs, practical documentation entry points, language status, and routes for learning and contribution.

## Start with what exists

The [tour](/ash/learn/tour/) shows complete programs for functions, data, and effects. The [status page](/ash/status/) separates specified capabilities from experimental work and research direction. These pages identify their reviewed compiler checkpoint.

This is a website implementation milestone, not an Ash language release or a production deployment announcement.

## Preserve the study work

Ash-doc remains separate. [Study Ash](/ash/study/) points to its unpublished source material, with its own target, examples, and checks. A published edition can later sit beneath the same public home without losing its book outputs or independent verification.

## What comes next

The current version is available for local review. Production hosting and a domain remain to be selected. Study edition embedding will follow publication readiness; it is not required to read the current source material.

Use [Contribute](/ash/contribute/) to find the project and participate in its next steps.
