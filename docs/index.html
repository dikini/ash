Build the tool, run a program, and find the right source for a precise answer.

Reviewed 19 October 2026

Use these entry points to move from an introduction to a working program or a precise language rule.

Get running

Install the pinned Ash tool and run a complete example from the short tour. The current tool is built from source. No packaged installer is offered here.

Language reference

Read the Ash specification on this site, with railroad diagrams for the grammar and proof trees for inference rules. Its chapters cover:

  • Source text and tokens
  • Syntax
  • Names, imports, and scope
  • Types and checking
  • Elaboration into typed Core
  • Evaluation

The specification is imported from ash-lang main at build time. Each page links to its exact source revision. It may describe a newer language than the compiler checkpoint used by the tour.

Command-line tool

Read the ash tool guide for invocation, builds, module roots, output, diagnostics, locales, and failure statuses. The tools overview links the available executables.

The guide and specification come from the same ash-lang revision. The installation instructions and tour retain their pinned compiler checkpoint; use the guide’s source revision when exploring newer commands.

Design notes

Explore the design notes for research, alternatives, experiments, and supporting evidence. These documents are informative; proposals may be incomplete or superseded. Use the language specification for current rules.

Architectural decisions

Read the architectural decisions for accepted choices about the parser, compiler representations, evaluation, tooling, and repository workflow. Each record retains its status, context, consequences, and verification requirements. These choices concern non-language architecture; the specification defines current language rules.

Decisions, design notes, the specification, and the tool guide share the same imported ash-lang revision.

Lessons and worked programs

Study Ash leads to ash-doc’s sequential lessons, examples, exercises, and cases. Its current study target is separate from the website’s language checkpoint. Use the instructions accompanying the material you choose.

Before planning a project

Read language status for implemented capabilities, experimental boundaries, and missing facilities. Contribute explains how to investigate or help.
