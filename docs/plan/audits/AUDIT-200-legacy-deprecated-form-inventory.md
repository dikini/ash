# AUDIT-200: Legacy/Deprecated Form Inventory

**Status:** Complete for TASK-1952 audit gate
**Task:** [TASK-1952](../tasks/TASK-1952-legacy-deprecated-form-audit.md)

## Scope

This audit classifies legacy/deprecated form hits across the live Phase 200 migration surfaces:
diagnostic tests, LSP tests, productive docs/reference/spec paths, examples, templates, stdlib
comments/surfaces, and compatibility fixtures. The gate records file/pattern pairs rather than
every matching line so follow-up work can track ownership without making the inventory brittle to
line movement.

Classifications are:

- `removed`: the old form was removed from the scanned surface.
- `migrated`: the old form was rewritten to current syntax.
- `compatibility-only`: retained only as an explicitly tracked compatibility or migration fixture.
- `historical/reference-only`: retained only in historical/reference material, excluded from
  productive examples, templates, tutorials, formatter, and LSP happy paths.
- `retained-with-migration-diagnostic`: retained in an accepted path only when diagnostics guide
  users toward current syntax.
